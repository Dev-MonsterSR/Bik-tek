Gestos Disponibles

Apuntar (Pointing)

Acción: Controla un cursor virtual. Mantén 1 segundo para hacer clic.

✋

Palma Abierta (Open Palm)

Cómo: Extiende todos tus dedos

Acción: Pausa temporal del control de gestos.

⬆️

Acción: Desplaza la página hacia arriba.

⬇️

Deslizar Abajo (Swipe Down)

Cómo: Mueve tu mano hacia abajo rápidamente

Acción: Desplaza la página hacia abajo.

¿Cómo Activar?

  1. Busca el botón flotante azul con ícono de mano en la esquina inferior izquierda
  2. Haz clic para activar el control por gestos
  3. Permite el acceso a tu cámara web cuando el navegador lo solicite
  4. Verás una pequeña ventana con la vista de tu cámara en la esquina inferior derecha
  5. ¡Comienza a usar gestos! El cursor virtual aparecerá siguiendo tu dedo índice

Requisitos

  • Navegador moderno (Chrome, Edge, Firefox, Safari)
  • Cámara web funcional
  • Buena iluminación ambiente
  • Permisos de cámara activados
  • Conexión a internet estable
  • Fondo uniforme (recomendado)

Consejos para Mejor Uso

Tip 1: Mantén tu mano a 30-60 cm de la cámara para mejor detección.
Tip 2: Los gestos deben ser claros y deliberados para mejor reconocimiento.
Tip 3: La buena iluminación mejora significativamente la precisión del seguimiento.
